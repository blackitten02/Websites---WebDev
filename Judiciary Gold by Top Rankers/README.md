# Judiciary Gold — Website Mockup

A polished, responsive one-page concept for **Judiciary Gold by Toprankers**, created for the 07 August 2026 design task.

## Concept

**Positioning:** “From classroom to courtroom.”  
**Visual direction:** premium editorial education brand; warm ivory, charcoal and judicial gold; restrained serif typography; confident but student-friendly interactions.

## Included

- Responsive desktop, tablet and mobile layouts
- Hero, impact metrics and program discovery
- Persona-based course filters
- Interactive Prelims / Mains / Interview journey
- Results, mentorship dashboard and centre network
- Resources, accessible FAQ accordion and conversion-focused CTA
- Mobile navigation and counselling modal with form success state
- Scroll reveals, counters and reduced-motion support
- Keyboard-accessible navigation, tabs, accordions and dialog
- No framework, external font, CDN or runtime dependency

## Run locally

From this folder:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Files

- `index.html` — semantic page structure
- `styles.css` — responsive visual system
- `script.js` — interactions and accessibility behavior
- `assets/` — local, preview-safe imagery and favicon

## Content note

This is a **concept mockup**, not a production deployment. Publicly available Judiciary Gold positioning and July/August 2026 Toprankers information informed the content, including 500+ selections, 8,000+ students, 11+ centres and listed top-ranked results. Any production version should pass final copy, result-year, course, pricing, location and contact details through the brand/legal review process.
